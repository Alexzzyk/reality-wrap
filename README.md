# REALITY WRAP

**现实锚定式空间图形改造 Skill**：保留实拍主体的摄影质感，默认以大色块和巨幅扁平插画主导可改背景，让图形服从载体、透视、遮挡与光照。

适用于 Codex，以及能读取 Markdown 技能规范、观察图片并执行图像编辑的 AI 环境。

## 安装到 Codex

将仓库克隆到一个新的技能目录；已有同名技能时请先核对版本，不要直接覆盖。

```sh
git clone https://github.com/Alexzzyk/reality-wrap.git "${CODEX_HOME:-$HOME/.codex}/skills/reality-wrap"
```

重新打开聊天或刷新技能列表。上传实拍照片后调用：

```text
使用 $reality-wrap 改造这张照片，保留主体外观与身份，让大色块和巨幅插画主导可改背景，形成有空间逻辑的完整图形世界。
```

只需要提示词时：

```text
使用 $reality-wrap 分析这张照片，只输出图生图 Prompt，不生成图片。
```

## 1.1.1 默认强度

默认 `strong-campaign`：大面积图形环境、巨幅母题、连贯背景延展。主体保真与环境空间骨架单独保护，表面材质可整体图形化。用户要求轻度或只改某个局部时用 `subtle-surface`。

生成后同时检查介入面积、图形尺度、背景主导性；小墙绘或稀疏贴纸不满足默认模式。参考面积范围是设计估计，不是硬配额；不为凑面积覆盖主体。实际质量仍受输入照片与生成工具影响。

## 工作方式

1. 读取目标照片，区分目标与风格参考。
2. 划定主体、文字、结构保护区。
3. 找到可改造的现实表面并分析透视、光线与遮挡。
4. 按照片内容建立统一的主题、配色和图形词典。
5. 调用可用的图像编辑工具，默认交付一张改图。
6. 对照原图检查主体、结构、文字、空间融合与材质，必要时定向修订。

包含人像、汽车、商品/食品、建筑、城市街景、宠物六类策略。静态照片不会自动套追焦；主体位置、具体颜色、图案内容和介入面积随输入变化。

## 工具与保真边界

本仓库提供技能规范，不包含图像模型、API 服务或自动执行程序。实际改图需运行环境提供图像编辑工具；Codex 中优先使用内置 image_gen。其他环境应按其实际工具接口执行，不能直接假设拥有相同参数。

没有编辑工具时可以输出可执行 Prompt，并明确尚未生成。提示词中的主体锁定是目标，不能保证逐像素保留。人脸、商品标签、牌匾文字、窗口等仍须对照检查；严格保真需保留原主体图层及可验证的合成流程。

本包不附带固定风格参考图片；可使用你有权使用的实拍照片和风格参考。references/examples.md 为假设输入的提示词演示；examples/ 为实际生成的对比案例，二者分别标示。
