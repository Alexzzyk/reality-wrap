# 原图—结果复核

每次生成后对照原图与结果实际像素。结果有本地路径时使用 `view_image`；工具已返回可见图片时直接检查。逐项标为通过、失败或未验证；无结果不填写通过。记录可见差异，不用综合“审美分”抵消关键缺陷。

## 规模门槛：默认强介入必须检查

- 缩略图看：是否立即读到“大面积插画环境＋真实摄影主体”？只看到几条彩绘则失败。
- 是否存在连续主图形区域，视觉面积与照片可用空间/参考强度相称？不冒充已经像素测量。
- 母题是否足够大，能跨越主载体较大区段，形成大块形状？密集小花纹不替代尺度。
- 大面积天空/背景留白是否经过设计判断？无保护理由却保持全部真实、导致插画明显不足时应扩大背景。
- 低密度区是否兼顾视觉主导性？可用奶油白与纯色图形呼吸，不通过减回摄影面积来削弱强度。

面积、尺度、背景主导性任何一项不符，都要按强介入模式定向修订，不能因主体相似便判为通过。

## 关键检查

| 项目 | 原图对照依据 | 不通过示例 |
|---|---|---|
| Subject | 轮廓、位置、数量、形状、姿态 | 新增肢体、轮子改型、商品尺寸变化 |
| Identity | 脸/发型、Logo、文字、包装、动物特征 | 换脸、标签变字、牌照变化 |
| Perspective | 转角、平面收缩、门窗、遮挡 | 斜墙上正视图案、框架被抹掉 |
| Lighting | 光向、接触阴影、表面明暗 | 物体悬空、投影方向冲突 |
| Composition | 主体可读性、主图形区、净区 | 图形抢脸、全屏等密度 |
| Graphic density | 主块与母题层级 | 碎花覆盖所有空间 |
| Color | 配色系统、摄影颜色与连接色 | 肤色变橙、食物颜色失真 |
| Photography | 原景深、动静、材质与边缘 | 毛发变塑料、静物被追焦 |
| AI artifacts | 手、轮胎、重复物、文字与接缝 | 假字、复制窗、边缘光圈 |
| Commercial quality | 可解释的载体、统一图形系统、用途适配 | 无关装饰，品牌信息错误 |

## 修订顺序与停止条件

先修主体/身份/关键文字/空间骨架；强模式的介入面积、母题尺度和视觉主导性也是验收门槛。结构骨架与表皮外观分开判定，允许的图形改造不是结构失真。随后处理透视遮挡、光照、密度和配色。每轮写明一个主要问题、目标改动和其他保护项，重新引用原图。默认最多两轮；用户明确要求继续时再处理。

关键项未通过时标为“概念版本，尚未通过主体/结构复核”，不输出“完全保真”“可直接商用”。视觉复核不能证明逐像素一致；若用户要求精确保真，原主体保留图层或相应像素/文字核对才是可靠证据。

没有本地文件时不捏造尺寸、文件格式或保存位置。文件已保存时可以实测宽高/比例，但尺寸通过不等于视觉通过。

最终用一两句交代真实结果，例如：“已检查主体轮廓、墙面转角、遮挡与光色；包装小字无法确认，需以原包装精确合成。”不要把未验证项藏在笼统的通过结论里。
